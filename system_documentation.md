# 🏛️ SesekaliCBT (ExamFlow) - Comprehensive System Documentation

## 🌟 1. System Overview
**SesekaliCBT** (formerly known as ExamFlow) is a premium, enterprise-grade Learning Management System (LMS) and Computer-Based Test (CBT) platform. It is engineered to provide a high-security environment for academic assessments while fostering student engagement through real-time gamification and a robust administrative suite.

### 🏗️ Tech Stack
-   **Framework**: Laravel 12.x (Enterprise PHP Framework)
-   **Architecture**: Monolithic SSR with Optimized Client-Side Interactivity.
-   **Frontend**: Tailwind CSS 4.x (Performance-first logic), Alpine.js (Lightweight reactivity).
-   **Real-time Engine**: Redis-backed State Machine with Optimized AJAX Polling.
-   **Security**: AES-256 Metadata Encryption and Focus Detection Listeners.

## 🛡️ 2. CBT Engine & Academic Integrity
The core of SesekaliCBT is its high-performance exam engine, designed to handle hundreds of concurrent participants on standard hosting environments.

### 2.1 Exam Lifecycle
1.  **Drafting**: Teachers create questions in the **Bank Soal** (supports Rich Text, Mathematics via KaTeX, and High-Resolution Images).
2.  **Deployment**: Exams are assigned to specific classes with custom durations, passing scores (KKM), and scoring weights.
3.  **Tokenized Gating**: Access is controlled via transient, 6-character alphanumeric tokens generated by the supervisor, valid only for current sessions.
4.  **Live Taking**: Students experience a seamless, single-page interface. **Auto-Save** logic ensures answers are persisted every few seconds or upon every interaction.
5.  **Grading**: Instant auto-grading for Multiple Choice (PG). Essay questions are routed to the Teacher Dashboard for manual evaluation with feedback.

### 2.2 Advanced Anti-Cheat System
SesekaliCBT implements a "Zero-Trust" student interface:
-   **Focus Detection**: Monitoring `onblur`, `visibilitychange`, and `document.hasFocus()` to detect if a student opens other tabs, applications, or split-screens.
-   **Strike-Limit System**: Configurable violation limits (e.g., 3 strikes). Upon exceeding the limit, the system triggers an **Auto-Submit**, locking the session immediately.
-   **Heartbeat Monitor**: Real-time connectivity tracking. Supervisors are alerted if a student's "Heartbeat" stops, indicating potential network tempering or hardware failure.

## 🕹️ 3. Battle Arena V2 (Gamification)
To increase student engagement and motivation, SesekaliCBT features a world-class gamification engine.

### 3.1 Competitive Mechanics
-   **Live Battle Rooms**: Teachers can initiate "Battle Rooms" where students compete in real-time.
-   **Group Mode & Solo Mode**: Supports individual competition or team-based battles with aggregated scores.
-   **Real-time Leaderboard**: Dynamic ranking updates based on speed and accuracy.
-   **The Podium Reveal**: A celebratory animated sequence at the end of each battle, highlighting the Top 3 winners (Gold, Silver, Bronze).

### 3.2 Progression & Rewards
-   **XP & Leveling System**: Students earn Experience Points (XP) for every correct answer and battle participation.
-   **Shop & Customization**: Unlocked items including **Avatars**, **UI Themes** (Dark Mode, Glassmorphism, etc.), and **Power-up Cards**.
-   **Seasons & Hall of Fame**: Monthly or semester-based seasons with permanent records for top achievers.

## 📂 4. Administrative & Professional Suite
Beyond testing, SesekaliCBT serves as a complete administrative hub for educational institutions.

### 4.1 Smart Letter Generation
-   **Template Engine**: Create professional documents (SPPD, SK Aktif, etc.) using a dynamic placeholder system (`[[nama_lengkap]]`, `[[nis]]`, etc.).
-   **Bulk Processing**: Generate hundreds of PDF documents in seconds with automated data mapping.
-   **Self-Service Portal**: Students/Parents can request and download validated letters directly from their dashboard.

### 4.2 Extracurricular & Internship (DUDI)
-   **Activity Tracking**: Management of student extracurricular activities, coach attendance, and participation logs.
-   **Internship (DUDI) Portal**: Specialized module for tracking student placements in industries (Praktek Kerja Lapangan), including supervisor evaluations and attendance logs.

## 📊 5. User Roles & Access Control
The system uses a **Subject-Based RBAC** to ensure data privacy and organizational efficiency.

| Role | Core Responsibilities | Data Visibility |
| :--- | :--- | :--- |
| **Superadmin** | System Config, User Management, Log Audits | Full System |
| **Teacher** | Bank Soal, Exam Management, Grading | Only assigned subjects & classes |
| **Principal** | Academic performance monitoring, Stats, Reports | School-wide aggregated data |
| **Staff (TU)** | Administrative letters, Student records, DUDI | Administrative modules |
| **Student** | Taking exams, Battles, Rewards, Profiles | Individual data & Public rankings |

## ⚙️ 6. Performance Optimization
SesekaliCBT is built for speed and reliability:
-   **Redis Cache Layer**: Used for session management and real-time state tracking to minimize database I/O.
-   **Image Optimization**: Automatic resizing and compression of all uploaded assets.
-   **Throttling & Rate-Limiting**: Smart middleware prevents server overload during high-traffic exam starts.
-   **Maintenance Mode**: Admin can schedule system-wide maintenance with custom messaging without dropping active exam sessions.
